# Kotlin Worksheet 0.7.0 Release Readiness Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Complete Arrow-kt dependency validation, harden Gradle classpath cache invalidation, and make the 0.7.0 release candidate internally consistent and verifiable.

**Architecture:** Keep Gradle classpath caching in memory, keyed by project root, worksheet directory, and detected Gradle command. Add a small Kotlin JVM Gradle fixture that resolves Arrow Core from Maven Central and exercise it through the existing `resolveGradleClasspath` and `executeWorksheet` paths. Update release documentation without changing the publishing workflow's explicit tag and Marketplace boundaries.

**Tech Stack:** TypeScript, VS Code Extension API, Vitest, Mocha VS Code integration tests, Gradle 8.10.2, Kotlin/JVM 2.4.0, Arrow Core 2.2.3, pnpm, `@vscode/vsce`.

## Global Constraints

- The release must validate Arrow-kt APIs through a Kotlin JVM Gradle runtime classpath.
- Arrow Core must be pinned to `2.2.3` and resolved from Maven Central.
- The Kotlin test toolchain remains pinned to `2.4.0`.
- The cache remains in-memory; no persistent cache is introduced.
- Android, Kotlin Multiplatform, and custom Gradle source-set layouts remain unsupported.
- A refresh must prevent completed and in-flight stale work from repopulating the cache.
- Existing cache status values and logging remain unchanged.
- No automatic tag creation or Marketplace publishing is added.
- Do not commit changes unless explicitly requested by the user.

- [ ] **Step 1: Write a failing refresh-during-resolution test.**

Add a deferred-resolution test that starts one request, clears the project, starts a second request, and resolves the old request first:

```ts
it("does not repopulate the cache from a request started before refresh", async () => {
  let calls = 0;
  const resolvers: Array<(result: GradleClasspathResult) => void> = [];
  const cache = new GradleClasspathCache({
    detectCommand: async () => ({ command: "gradle", args: [] }),
    fingerprint: async () => "same",
    resolveClasspath: async () => {
      calls += 1;
      return await new Promise<GradleClasspathResult>((resolve) => resolvers.push(resolve));
    },
  });

  const first = cache.resolve("/project", { timeoutMs: 1000 });
  await Promise.resolve();
  await Promise.resolve();
  expect(cache.clear("/project")).toBe(0);

  const second = cache.resolve("/project", { timeoutMs: 1000 });
  expect(calls).toBe(2);

  resolvers[0](successfulClasspath(["/stale"]));
  resolvers[1](successfulClasspath(["/fresh"]));

  expect((await first).classpath).toEqual(["/stale"]);
  expect((await second).classpath).toEqual(["/fresh"]);
  const third = await cache.resolve("/project", { timeoutMs: 1000 });
  expect(third.cacheStatus).toBe("hit");
  expect(third.classpath).toEqual(["/fresh"]);
});
```
